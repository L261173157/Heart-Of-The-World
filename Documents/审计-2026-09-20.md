# 全面体检报告（2026-09-20）

上一次全面体检为 2026-09-13，此后落地美术 v5 NA 主题化、玩法 v7 物品三批、iOS 横屏 v6、真机性能两轮（f4ede75..5d8af50，21 提交 +4.3 万行）。本轮对增量代码面与核心模块做全面 bug/优化排查：3 个探索代理模式扫描（信号配对/物理回调/每帧分配/存档迁移/UI 边界）+ 主会话逐条源码核实 + 补测试实证。基线六测+perf_probe 全绿，收口全量回归全绿。

## 一、已修复（10 项，全部带回归验证）

### P0 级（数据丢失/玩法断裂）

**1. 存档加载断链——非狩猎任务让 `_load` 中途崩溃**（`game_state.gd _load` 任务消毒段，**补盲区测试时新发现，审计静态扫描未覆盖**）
旧代码 `if typeof(qd.get("species", "")) == TYPE_STRING: qd["species"] = migrate_name(qd["species"])`——默认值 `""` 本身是 String，捣巢/探索/收集任务（占四分之三任务类型）**没有 species 键**，条件恒真后取 `qd["species"]` 直接键缺失报错，`_load` 中途中断：**其后加载的物品栏/已发现地标/最后保存时间全部丢失**。v7 P1（09-19）上线后真实玩家接任意非狩猎任务并存档即触发。同族问题两处一并修：`settings` 音量回退值 `settings[key]` 假设内存键必存在（缺键同款崩溃）；缺 id 的坏条目因 `get("id","")` 默认值是 String 而溜过类型门（HUD 读 title/kind 即崩）——消毒门改为 id 非空 String + need 数值 + kind/title String 全验。
验证：save_test 新增 7 断言（任务往返/坏条目四类丢弃/獾王→锹形虫王更名迁移/进度超钳/完成数消毒/settings 白名单与音量钳制/未来版本档容错）。

**2. 城塞宝箱可无限重开刷奖励**（`game_world.gd _update_dungeons`/`DungeonChest`）
`taken` 只存于节点，宝箱流式离场（>1400px `queue_free`）后重进即重置未开——Boss 死亡窗口内「开箱→走远→回来→再开」，银钥匙精英怪可刷 → 无限金币+物品循环。修复：taken 上移 `game_world._chest_taken` 字典（patch_id→bool），节点重建时同步读回，Boss 复活分支清键（保留"下一轮可再开"原语义）。
验证：combat_test 新增 3 断言（开箱写标记/流式往返保持已开/Boss 复活重置）。

**3. 任务结算顺序错误——扣料失败时任务蒸发**（`quest_manager.gd _complete`/`accept`）
`_complete` 先销单+completed++ 再扣材料；接单确认前的 12s 气泡窗口内把材料卖到低于 need 即触发：任务没了、NPC 完成数已加（改变后续委托生成的确定性序列）、奖励没发。修复：材料校验挪到销单之前（不足=不销单不计数，进度回落当前持有等再攒，与注释语义一致）；`accept` 时按当前持有重算 progress 快照。
验证：combat_test 新增 2 断言（库存不足不销单不计数不发奖/补货后经拾取信号正常结算）。

**4. lambda 悬连 5 处——二周目世界对已释放节点悬空调用**（世界生命期节点连长命信号）
tutorial(player_died)、achievement_manager(species_extinct/recovered/leveled_up)、player(leveled_up→fx)、quest_manager(dialogue_confirmed)、main_menu(viewport size_changed) 均用 lambda 连 EventBus/GameState.stats/Viewport——lambda 捕获 self 不受"对象释放自动断连"保护（tutorial.gd 自己的注释早已记录此坑但只修了定时器侧）。回主菜单后再进世界，同信号触发即对 freed 实例调用：报错刷屏/特效错位/潜在崩溃。修复：全部改方法引用连接（随对象释放自动断连，无需手动 disconnect）。
验证：ui_flow_test 双周目路径（世界→菜单→继续）全绿无 freed instance 报错。

### P1 级（体验/工程）

**5. 音乐优先级被换区监听旁路**（`sfx_manager.gd` ↔ `game_world._refresh_music`）
SfxManager 的 `player_entered_region` 处理器无条件切群系曲；Boss 临场/城塞/营地中进行中跨区，战斗曲被抢占且 `_music_mode` 未变调度器不纠回——战斗 BGM 丢失直到脱离特殊区。修复：切曲权威全收 game_world（SfxManager 处理器只留换区 chime），`_commit_region` 仅在 `_music_mode==""` 时切群系曲。
验证：combat_test 新增 3 断言（Boss 临场切入战斗曲/跨区不抢占/脱离回落）。

**6. 读档首曲双重淡入淡出**（`game_world._commit_region` 首区域提交）
出生点常在营地内：先播群系曲、0.25s 后被首个 `_refresh_music` 纠正成营地曲——每次进世界必现一次双切。修复：首区域提交时同步一次营地/城塞判定再定首曲。

**7. 钥匙经济：凭证可整叠卖光且背包不可见**（`hud.gd` 收购页/物品栏）
金/银钥匙挂在 `EconomyMath.ITEM_SELL` 里被收购页整叠卖出（金钥匙仅收集委托可得，误卖锁死 lava 城塞闭环）；且 `kind="key"` 不进物品栏弹层，玩家无任何常驻 UI 可查持有量。修复：收购页过滤 key 类（ITEM_SELL 表保留钥匙 id——`knows_item` 存档消毒认证依赖它）；物品栏增加钥匙栏位，点击播报用途。
验证：combat_test 既有钥匙闭环断言 + 物品栏改动经 ui_flow 冒烟。

**8. 对话气泡无距离关闭——走开后攻击键仍被改道**（`hud.gd` + `game_world.LandmarkNPC`）
气泡常开最长 12s，期间攻击键=确认/冲刺=关闭；中途走开气泡仍在屏，远处按攻击会误接旧委托单。修复：`npc_dialogue` 载荷补 `origin`（NPC 世界位置），HUD 每帧（仅气泡可见时）判玩家距离 >180px 自动收气泡。

**9. await 悬空恢复**（`game_world._layer_physics_selfcheck`）
`await get_tree().create_timer(2.0)` 的 SceneTree 定时器随树存活，2s 窗口内回主菜单会在已释放节点上恢复协程（freed instance 报错）。修复：改子 Timer 节点 + 方法引用（随世界释放自动断连）。

**10. 工程卫生**
- 删仓库根 `{{pketc}}/cert.pem` 死符号链接（指向不存在的 `{{etc}}/...`，某工具模板变量未展开产物）
- 删 `fx_*_frames 2.tres` 重复副本 ×44（每个 fx 目录两份自包含内嵌贴图资源；切片工具只输出单份，系 iCloud 同步冲突副本——零代码引用、白进 PCK 体积）
- settings 默认字典补 `auto_aim: false`（读档白名单有此键、默认字典没有，不同步）
- 宝箱 `boss_name` 查空（地形没配 Boss）永久 locked 加防御（视为无主宝箱直接解锁；当前配置不触发，纯防御）
