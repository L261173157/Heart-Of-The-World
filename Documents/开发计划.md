# 《心之世界》开发计划

> 本文档记录当前开发范围与里程碑决策；`策划纲要.md` 保留为长期愿景文档，两者冲突时以本文档为准。
> 制定日期：2026-09-01

## 一、已确认的核心决策（2026-09-01）

| 决策项 | 结论 | 原因 |
|---|---|---|
| 技术栈 | Godot 4.7（Steam 标准版）+ **纯 GDScript** | C# 在 iOS 仍是实验性支持（NativeAOT、无模拟器导出）；2D 游戏 GDScript 性能足够 |
| 平台 | iOS 优先 | 目标平台；横屏 |
| 联网形态 | **先单机，后加联机** | 个人开发者先验证玩法；生态模拟本地跑，零服务器成本 |
| 核心系统 | 怪物生态自演化 + ACT 无锁定战斗 + 角色养成 | 生态自演化是本作最独特的卖点 |
| 后置系统 | 社交/公会/交易/PVP/任务/NPC | 强依赖联机或非核心，进待定池 |
| 服务器 | M2 阶段再选（候选：Nakama 开源版 + VPS） | 单机阶段不需要；届时战斗改服务器权威 |
| 开发节奏 | 业余时间（<10h/周） | M0 目标 3–4 个月 |

## 二、架构约定（详见 Code/AGENTS.md，此处摘要）

- `scripts/ecology/` 为**纯逻辑层**（RefCounted/Resource + 信号，禁止引用 Node/场景树），未来整体平移到服务器做权威模拟
- 表现层（Node）只通过信号/快照消费模拟状态，不直接改写
- 所有输入抽象为 Input Map 动作或经 TouchInput autoload，键盘（开发）与触屏（iOS）同源
- 跨模块通信一律走 EventBus 信号

## 五、风险与原则

1. **范围膨胀是最大风险**：本作愿景是 MMO 级，砍掉 80% 才适合个人业余开发。改需求先改本文档，再动代码。
2. **美术是隐形大头**：原型期一律占位素材，禁止自制美术。
3. **iCloud 同步**：仓库在 iCloud Drive 路径下，`.godot/` 缓存若被同步干扰导致构建异常，先清理再重试。
4. **数值公式**：~~当前所有公式为 v0 占位，M1 做一次统一数值设计。~~ 已完成（2026-09-03，见《数值设计-M1.md》）；后续改数值只动单一事实源定义处，balance_test/pacing_test 自动守闸。
5. **上架判定**：玩法/商业可行性评估见《玩法与商业评估-2026-09-01.md》，以 TestFlight 真实数据（留存/付费意愿）为最终裁决，不以主观判断代替。
